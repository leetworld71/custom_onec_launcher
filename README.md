# 1C Launcher

Быстрый запуск информационных баз «1С:Предприятие 8.3» для Windows. Показывает тот же список баз, что и стандартное окно запуска 1С, но открывает Предприятие и Конфигуратор напрямую, через параметры командной строки, поэтому заметно быстрее.

*A fast, dark/light themed launcher for 1C:Enterprise 8.3 infobases on Windows. UI is in Russian.*

> Неофициальный проект. Не связан с фирмой «1С». «1С» и «1С:Предприятие» — товарные знаки их правообладателя.

## Возможности

- Список баз из стандартного файла 1С (`ibases.v8i`): изменения видны и в лаунчере, и в окне запуска 1С.
- Запуск **1С:Предприятия** и **Конфигуратора** одной кнопкой или клавишами (`Enter` / `Ctrl+Enter`).
- Подсветка запущенных баз: метки «Предприятие» и «Конфигуратор», закрытие окна 1С крестиком в метке, кнопка «Закрыть все 1С».
- Показывает точную команду запуска для выбранной базы и копирует её в буфер обмена.
- Создание новой пустой базы, добавление существующей (файловой, серверной или на веб-сервере), изменение и удаление из списка.
- Параметры запуска базы, как в окне 1С: основной режим (автоматически / тонкий / толстый клиент), скорость соединения (обычная / низкая, `/LowSpeed`), версия и разрядность платформы, дополнительные параметры командной строки. Версия и разрядность выбирают нужную платформу, если их установлено несколько.
- Флаги-подсказки под полем дополнительных параметров: клик добавляет флаг в поле, повторный клик убирает. Есть «Современный дизайн» (`/C"design=modern"`), «Дизайн с тёмной панелью» (`/C"design=dark"`), «Режим техн. специалиста» (`/TechnicalSpecialistMode`) и «Отладка» (`/Debug`). Флаги дизайна действуют в базах, конфигурация которых их понимает (общий модуль «СовременныйДизайн»); остальные базы их не замечают.
- Необязательные пользователь и пароль для входа без окна авторизации. Имя пользователя запоминается для каждой базы, **пароль не сохраняется**.
- Настройки: тема (как в системе, светлая, тёмная, **моя тема**: цвета фона, панелей, полей, кнопок, текста, акцента и уведомлений в формате `#RRGGBB`, выбор цвета во встроенной палитре и кнопка «Создай за меня», которая подбирает случайную гармоничную тему), размер шрифта, размер кнопок, показ команд запуска, папка платформы.

## Установка

Скачайте файл со страницы релизов:

| Файл | Что это |
|---|---|
| `1C-Launcher-Setup.exe` | Установщик. Ставит программу для текущего пользователя, права администратора не нужны. |
| `1C-Launcher-portable.zip` | Вариант без установки: распакуйте и запустите `1C-Launcher.exe`. |

Установщик кладёт программу в `%LOCALAPPDATA%\Programs\1C Launcher`, создаёт ярлыки в меню «Пуск» и (по желанию) на рабочем столе. Удаление — через «Параметры → Приложения → Установленные приложения».

Файлы не подписаны цифровой подписью, поэтому Windows SmartScreen при первом запуске может показать предупреждение «Система Windows защитила ваш компьютер». Чтобы запустить, нажмите «Подробнее → Выполнить в любом случае».

Параметры установщика для автоматизации:

```
1C-Launcher-Setup.exe /silent               установка без окон
uninstall.exe /uninstall /silent            удаление без окон (настройки остаются)
uninstall.exe /uninstall /silent /purge     удаление вместе с настройками
```

## Требования

- Windows 10 или Windows 11. Проверялось на Windows 11 (сборка 26200).
- .NET Framework 4.6 или новее. В Windows 10 и 11 он уже есть, отдельно ставить ничего не нужно.
- Установленная платформа «1С:Предприятие 8.3». Проверялось с 8.3.27.

## Как лаунчер находит платформу

Берётся самая новая версия из найденных в таких местах:

1. папка из настроек лаунчера, если она указана;
2. `C:\Program Files\1cv8` и `C:\Program Files (x86)\1cv8`;
3. пути `InstalledLocation` из `1cestart.cfg`;
4. папка, из которой 1С зарегистрирована в Windows (COM-классы `V83.Application` и другие).

Если платформа стоит в нестандартной папке и не нашлась, укажите папку в настройках (кнопка с ползунками в верхней панели).

## Ограничения

- Интерфейс только на русском языке.
- Проверены файловые базы. Серверные базы (`Srvr=…;Ref=…`) запускаются через `/S`, но на реальном кластере не проверялись. Базы на веб-сервере (`ws=…`) передаются через `/IBConnectionString` и тоже не проверялись.
- Группы (папки) баз из окна 1С не отображаются: все базы показаны одним списком.
- Дополнительные параметры запуска хранятся только в настройках лаунчера, окно запуска 1С их не видит.
- Новая база создаётся только файловая и только пустая, без шаблона конфигурации.
- Запущенные базы определяются по командной строке процессов `1cv8.exe` и `1cv8c.exe` текущего пользователя.
- Кнопки закрытия отправляют окну 1С обычную команду закрытия; с зажатым `Shift` процесс снимается принудительно, и несохранённые изменения теряются.
- Если указан пароль, он передаётся 1С параметром `/P` в командной строке, как и при любом запуске 1С с параметрами. Пока 1С запущена, командную строку процесса могут увидеть другие программы этого пользователя.
- Цвет заголовка окна под тему меняется только в Windows 11.

## Где хранятся данные

| Что | Где |
|---|---|
| Список баз (общий с 1С) | `%APPDATA%\1C\1CEStart\ibases.v8i` |
| Копия списка перед первой записью в каждом запуске | `%APPDATA%\1C\1CEStart\ibases.v8i.launcher-bak` |
| Настройки лаунчера | `%APPDATA%\OneCLauncher\settings.txt` |

## Сборка из исходников

Нужен только Windows: используется компилятор C#, который входит в .NET Framework.

```
build.bat        собрать лаунчер, установщик и zip (результат в папке dist)
build.bat app    собрать только 1C-Launcher.exe
```

| Файл | Назначение |
|---|---|
| `Launcher.cs` | Лаунчер (WPF, разметка окон внутри файла). |
| `Setup.cs` | Установщик и программа удаления. |
| `make_icon.ps1` | Рисует значок `app.ico`. |
| `build.bat` | Сборка. |
